# NNLib 加速版准备包 —— 交接说明(方案商 xt-clang 环境专用)

> 2026-09-29。本包把 Silero VAD 的热点(~97% 计算量)替换为 Cadence NNLib 的 HiFi5
> f32 SIMD 内核,预期单窗耗时从数百 ms(GCC 软浮点,超 WDT)降到 **<5ms**,
> WDT 崩溃根除并直接达到量产性能。全程 f32 零量化,数值与参考实现一致(1e-5 量级)。
> **只能在 xt-clang(license)环境编译**——GCC 实测不可行(cstub 是 C 模拟层,详见
> ../integration/NNLib优化方案.md §6)。

## 包内容

| 文件 | 说明 |
|---|---|
| `silero_vad_nn.c` | NNLib 加速实现,接口与 silero_vad.c 完全相同,直接替换 |
| `准备包说明.md` | 本文件 |

NNLib 源码位置:XNNC SDK 的 `assets/library/nnlib/`(随 XNNC_3.2.2 分发,勿入公开仓库)。

## 集成步骤(在现有"交接三步"之上)

### ① 拷 NNLib 内核源(精确清单,共 9 个 .c + 头目录)

从 `XNNC/assets/library/nnlib/` 拷入 SDK `components/audio_algorithm/processor/src/nnlib/`:

```
src/algo/kernels/cnn/hifi5/xa_nn_conv1d_std_f32.c        (STFT 热点)
src/algo/kernels/matXvec/hifi5/xa_nn_matmul_f32.c        (全部 1x1 卷积)
src/algo/kernels/matXvec/hifi5/xa_nn_matXvec_f32.c       (LSTM 门)
src/algo/kernels/matXvec/hifi5/xa_nn_dot_prod_f32.c      (decoder FC)
src/algo/kernels/activations/hifi5/xa_nn_activations_f32_f32.c  (sigmoid/tanh/relu)
src/algo/kernels/basic/hifi5/xa_nn_elm_add_f32.c         (残差加)
src/algo/ndsp/hifi5/src/vec_sigmoidf_hifi5.c             (激活的 ndsp 底层)
src/algo/ndsp/hifi5/src/vec_tanhf_hifi5.c
src/algo/ndsp/hifi5/src/vec_reluf_hifi5.c
```

### ② 头文件 include 路径(加到 processor 的编译参数)

```
-I<nnlib>/src/include
-I<nnlib>/src/algo/common/include
-I<nnlib>/src/algo/ndsp/hifi5/include
-I<XtensaTools安装>/wq_hifi5_asic/src/cstub     (xtensa/tie/xt_hifi*.h 所在)
```
若 SConscript 自动扫描 src/*.c 编入,nnlib 子目录同样会被扫到(与算法文件同规则)。

### ③ 替换算法文件

`processor/src/silero_vad.c` → 换成 `silero_vad_nn.c`(其余 11 个集成文件不动:
权重/封装/HIL 全部复用)。silero_vad.c 留档改名 silero_vad_ref.c 即可回退。

### ④ 编译(xt-clang,7036AC)

贵司常规流程:defconfig 用自己的(ai.recorder 基线 + `CONFIG_VAD_ENABLE=y` +
`CONFIG_XT_TOOLCHAIN_XT_CLANG=y`),flash_layout dcore 300→400 扇区,正常 scons。
不需要 wq_gcc_shim.c 和 -Wno-error(那是 GCC 专用件)。

### ⑤ 烧录验证(和 B 包同流程)

上电 `[SHIL] begin windows=40` → 40 行 → `end`(xt-clang 版应在数秒内跑完);
日志 txt 发回,`python3 hil_parse.py <日志> golden_prob.f32`,**最大偏差 <0.1 验收**
(预期 <0.01;NNLib 与参考实现仅累加顺序不同)。
再用 wq-debug-tools 的 cpu_usage 量实际占用,给量产留档。

## 技术要点(给固件同事)

- **布局**:全网 [C][T] 行主序,与参考实现一致;权重零重排零转置。
  matmul 的 CHW 输出用 `out_offset=1, out_stride=vec_count`(见内核源码注释);
  conv1d 在 IC=1 时 CHW/HWC 同构;stride2 的 1x1 = 满算后抽偶数列(参考 §dwconv5 保留标量)
- **对齐**:f32 内核参数检查仅 4 字节;静态缓冲已加 aligned(16) 命中 matmul 快路径;
  可选优化:gen_weights.py 给权重数组加 aligned(16) 可让更多层走快路径
- **回退**:换回 silero_vad.c(或 silero_vad_ref.c)重编即回朴素 C 版
- **风险**:dwconv5(3% 计算量)保留标量实现,规避了 NNLib depthwise 布局歧义;
  若 [SHIL] 数值超线(不应发生),把 silero_vad_nn.c 的 conv1d 输出与参考版逐窗比对即可二分定位
