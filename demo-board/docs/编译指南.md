# Demo 板固件编译指南（Docker 全流程）

> 宿主: Apple Silicon macOS（x86-64 容器走 Rosetta）。Linux x86-64 主机去掉 colima/rosetta 相关步骤即可。
> 编译产物: `glass-stereo-dac-spi-nand-gd5f2gm7re-fatfs-ogg-7036AC-0.0.0.0.wpk`（刷机包）。

## 0. 前置一次性准备

### 0.1 编译镜像 `wq-build:latest`

镜像内含 xt-clang(RI-2020.4) + riscv64-gcc 14.2 + scons 环境，由方案商环境构建，
本仓库不含镜像本体。拿到镜像 tar 后:

```bash
docker load -i wq-build.tar          # 或按方案商说明构建
docker images | grep wq-build        # 确认存在
```

### 0.2 Colima VM（macOS 必须，注意 Rosetta）

```bash
colima stop 2>/dev/null; LIMA_HOME="$HOME/.colima/_lima" limactl start colima
# 首次启动前确认 lima.yaml 含 rosetta 块(colima start 重渲染会冲掉它):
#   rosetta:
#     enabled: true
#     binfmt: true
docker context use colima 2>/dev/null || \
  docker context create colima --docker "host=unix://$HOME/.colima/docker.sock"
docker info >/dev/null && echo "docker 就绪"
```

⚠️ 不要用 `colima start` 重新启动已存在的 VM——它会丢 rosetta 配置，amd64 退回 QEMU（慢一个数量级）。

### 0.3 license 目录（挂载进容器的 /wqcore）

```
wqcore/
├── toolchain/RI-2020.4-linux/XtensaTools/   # 方案商发的那份(公开版 license 校验不过)
├── toolchain/riscv64-unknown-elf-gcc-x86-64-14.2.0
└── licserv/x64_lsb/{lmgrd,xtensad}          # FlexNet license server
```

## 1. 还原工程树

## 2. 编译（一条命令，license server 拉起 + scons）

```bash
docker run --rm --platform linux/amd64 \
  --mac-address 00:15:5d:2b:42:e6 \
  -v ~/demo_work:/work \
  -v /path/to/wqcore:/wqcore \
  -w /work/wq-audio/wq-adk/examples/glass \
  wq-build:latest bash -c '
ln -sf /lib64/ld-linux-x86-64.so.2 /lib64/ld-lsb-x86-64.so.3
mkdir -p /usr/tmp/.flexlm
{ echo "SERVER localhost 00155d2b42e6 27000"; echo "VENDOR xtensad";
  cat /wqcore/toolchain/RI-2020.4-linux/XtensaTools/Tools/lic/license.dat; } > /tmp/lic.dat
export PATH=/wqcore/licserv/x64_lsb:$PATH
chmod +x /wqcore/licserv/x64_lsb/{lmgrd,xtensad}
lmgrd -c /tmp/lic.dat -l /tmp/lmgrd.log &
sleep 4
export LM_LICENSE_FILE=27000@localhost
export WQCORE_TOOLCHAIN_PATH=/wqcore/toolchain
scons --defconfig=config/7036AC/defconfig.record && scons -j16'
```

成功标志（末尾分区表, dcore ≤ 819200B 即分区放得下）:

```
glass-stereo-dac-spi-nand-gd5f2gm7re-fatfs-ogg-7036AC-0.0.0.0.wpk:
glass_dcore.bin   771808B   819200B(200)  94.21%
scons: done building targets.
```

产物在 `build/7036AC/glass-stereo-dac-spi-nand-gd5f2gm7re-fatfs-ogg/*.wpk`。

## 3. 烧录与日志

- 烧录: 研发烧录工具（烧录口 GPIO_01/02, XMODEM 2M；进下载模式 = 上电 GPIO_101 高）
- 日志口: GPIO_98/93, **2000000 8N1**（2M 波特率，普通串口工具看不到 1M/115200 的日志）
- 布局警告: 本分支 defconfig 用原厂分区表；若刷过其它分区布局的包，回刷官方包须整片重刷

## 4. 常见编译坑（30 秒速查）

| 症状 | 原因/解法 |
|---|---|
| FlexNet `-5,357` No such feature | license feature 名映射问题——必须走 lmgrd（上面第 2 步的完整流程），不能直读 license 文件 |
| 编译过了、链接报 license（-5,147） | 漏了 `--mac-address 00:15:5d:2b:42:e6`；且编译有增量缓存"看着过了"，改完重编 |
| 改了文件产物不变 | 改打包/链接类代码后要全清对应核 build 子目录；普通源码增量即可 |
| `scons -j16 \| head` 后构建静默中断 | 管道 SIGPIPE；输出重定向文件再过滤 |
| riscv 工具链秒退 | 1.4 ADK 要 riscv64-gcc 14.2（不是 10.2），确认 WQCORE_TOOLCHAIN_PATH 指对 |
| docker 里出现 `wq-audio/wq-audio` 空目录 | 挂载点层级错误的 virtiofs 影子目录，删掉并保持挂 `ai_record_bt_base:/work` |

## 5. 上板快速验收

上电后日志关键行（按顺序）:

1. `Second Bootloader` → `Boot from 0x341a0020`（正常启动, 无 rpc 断言循环）
2. **没有** `[SHIL]`（本分支已停用 HIL, 有则是旧包）
3. APP 连接使能 VAD 后: `[VAD] stream create` + `wq_sw_vad_init` + `[DFS] core2 send request 192`
4. 说话: `[SVs]7-done p=` 爬过 5000 → `wq_sw_vad_process hit` → `VG4 voice ingress accept:1 hit:1` → `app_record 3(STARTING) -> 4(RECORDING)`
